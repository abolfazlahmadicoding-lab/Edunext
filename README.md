# EduNext

A learning project: a Persian-language (RTL) educational website about programming languages and computer science topics, from beginner to advanced. Built with plain HTML, CSS and JavaScript, no frameworks.

> **Status: work in progress.** Only the home page is fully designed. The other pages are placeholders.

## Features

**Done**

- Home page layout and styling (hero, benefits, course cards, promo banner, reviews, newsletter, footer)
- Light/dark mode toggle that remembers the user's choice across pages (`localStorage`)
- Scroll-reveal animation: sections appear as you scroll to them (`IntersectionObserver`)

**Planned**

- Mobile navigation menu
- Course search and filter
- Form validation (login/sign-up, newsletter)
- Favorites list

## Tech

- HTML5
- CSS3 (custom properties, Grid, Flexbox, responsive layout)
- Vanilla JavaScript (no libraries or frameworks)

## How to Run

1. Download or clone the repository.
2. Open the folder in VS Code.
3. Right-click `index.html` and choose **Open with Live Server** (or just open `index.html` in a browser).

## About This Project

This is a learning project. AI tools were used to generate the HTML structure and CSS styling. All JavaScript (dark mode, localStorage, scroll reveal) was written by the developer.

# EduNext (فارسی)

یک پروژه‌ی آموزشی: سایت فارسی (راست‌به‌چپ) درباره‌ی زبان‌های برنامه‌نویسی و مباحث کامپیوتر، از مقدماتی تا پیشرفته. با HTML و CSS و JavaScript خالص، بدون فریم‌ورک.

> **وضعیت: در حال توسعه.** فقط صفحه‌ی اصلی کامل طراحی شده و بقیه‌ی صفحه‌ها فعلاً خالی هستند.

## قابلیت‌ها

**انجام‌شده**

- طراحی و استایل صفحه‌ی اصلی (بخش اصلی، مزایا، کارت دوره‌ها، بنر تخفیف، نظرات، خبرنامه و فوتر)
- دکمه‌ی تغییر حالت شب و روز که انتخاب کاربر را بین صفحه‌ها حفظ می‌کند (`localStorage`)
- نمایش بخش‌ها هنگام اسکرول (`IntersectionObserver`)

**برنامه‌ریزی‌شده**

- منوی موبایل
- جست‌وجو و فیلتر دوره‌ها
- اعتبارسنجی فرم‌ها (ورود و ثبت‌نام، خبرنامه)
- لیست علاقه‌مندی‌ها

## تکنولوژی‌ها

- HTML5
- CSS3 (متغیرها، Grid، Flexbox، طراحی واکنش‌گرا)
- JavaScript خالص (بدون کتابخانه و فریم‌ورک)
